# ALMA Import Manifest

This folder contains the ALMA runtime files used by DLC Gait Assembler.
The original ALMA checkout can remain in `DLC-Gait-Analysis-main/`; this folder is the smaller import that the app uses by default.

## Runtime Files

- `Functions/KinematicsFunctions.py`: stride/gait cycle detection, low-pass filtering, treadmill correction, spontaneous walking extraction, dragging detection, parameter calculation, and stickplot generation.
- `config.yaml`: ALMA default settings used to seed the gait-analysis GUI.

## Reference Files

- `LICENSE`: ALMA license copied with the imported implementation.
- `README.alma.md`: ALMA upstream README copied for reference.

No generated bytecode, demo videos, screenshots, or ALMA GUI panels are required by the current pipeline wrapper.
