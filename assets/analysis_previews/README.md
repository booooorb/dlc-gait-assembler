# Analysis preview provenance

`alma_reference_stickplot.svg` is generated by this repository's ALMA pipeline from
`tests/fixtures/alma/Demo_Mouse_Treadmill_30cm_s_650000_filtered.csv`.

It uses treadmill analysis at 30 cm/s and 120 fps with ALMA's ankle-to-toe reference
calibration. The asset is a real pipeline output used only by the no-processing UI
walkthrough. Completed automated runs continue to preview their own generated artifacts.

The eight SVGs in `alma_reference_alma_figures/` were generated by the repository's
ALMA representation pipeline from the official demo's real treadmill parameter table,
`tests/fixtures/alma/Treadmill(REAL)_30cm_s_650000_filtered_parameters.csv`.

The eighteen SVGs in `rustlab1/` are high-resolution (2400 px) preview renders of the
official RustLab1 representative runway outputs in
`DLC-Gait-Analysis-main/Output_Runway_Analysis/Output Figures/`. That upstream sample
contains representative baseline and three-days-post-injury recordings. The SVG wrapper
embeds the rendered official PDF page so Qt can display it sharply at any preview size.
The official RustLab1 previews contain both forelimb and hindlimb panels; generated
recording-specific figures show forelimb content when `Hindlimb + Forelimb` is selected.

Source documentation:

- ALMA: https://github.com/sollan/alma
- RustLab1: https://github.com/rustlab1/DLC-Gait-Analysis

PCA and random-forest outputs are intentionally not part of this preview catalog.
